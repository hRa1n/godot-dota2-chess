# godot-dota2-chess

用 Godot 4.7 制作的回合制卡牌棋子游戏（MOBA 风格），免费、非商业的同人作品。

**在线试玩：（GitHub Pages 地址见仓库 Settings → Pages）**目前是本地双人（同一台设备轮流操作）的测试版。

## 规则（当前版本）

坐标写法：**行-列**，从 1 开始（棋盘 11×11）。

- 阵营：天辉（绿，下方）vs 夜魇（红，上方）
- 泉水：天辉 11-6（下边中间），夜魇 1-6（上边中间）；能量圈在正中 6-6
- 一个棋子 = 一个角色；选中棋子后，左侧显示它的基础攻击卡，底部是本方手牌
- 双方轮流行动，**每回合只能操作一个棋子**：移动一次（可选）+ 使用该棋子的一张卡牌（可选），顺序不限
- 一旦移动或出牌，本回合就锁定为这个棋子；移动和出牌都用完后自动结束回合，也可以随时点「结束回合」
- 移动：上下左右走，不能穿过棋子和泉水，最多走「移动速度」格
- 物理伤害：实际伤害 = 卡牌伤害 − 目标防御，至少 1 点
- 泉水：每个己方回合开始时，泉水周围 5×5 内的己方棋子 +2 血；并随机攻击范围内一个敌人，造成 5 点伤害（无视防御）
- 胜利：
  - 站上能量圈，之后连续 2 个己方回合开始时仍站在上面 → 获胜（离开或阵亡就清零）
  - 或者消灭对方全部棋子

## 阵容

| 阵营 | 英雄 | 小兵 |
|---|---|---|
| 天辉（下） | 水晶室女、宙斯、剑圣 | 4 |
| 夜魇（上） | 斧王、混沌骑士、屠夫 | 4 |

所有棋子目前属性相同：血量 5 / 防御 0 / 移动 5；每个棋子都有基础攻击卡（3×3 范围，物理伤害 2）。

## 资源卡（抽牌）

- 每个己方回合开始抽 2 张，手牌上限 8（多抽的直接弃掉），牌库抽空后把弃牌洗回去
- 牌库 = 本方 3 个英雄的技能卡各 2 张 + 5 种装备各 2 张（共 28 张）
- 出牌规则不变：每回合只操作一个棋子，出一张牌（基础攻击，或手牌里它能用的资源卡）
- 技能卡只有对应英雄能用；装备卡任何棋子都能用，装给本回合行动的棋子
- 魔法伤害无视防御；物理伤害 = 伤害 − 防御，至少 1

| 英雄 | 技能 1 | 技能 2 | 技能 3 |
|---|---|---|---|
| 宙斯 | 连锁闪电：7×7 内一敌 2 点，弹射 2 个各 1 点 | 雷击：11×11 内一敌 3 点 | 天罚：全场敌人各 1 点 |
| 水晶室女 | 冰霜新星：9×9 内选敌，其周围 3×3 敌人各 1 点 | 冰封禁制：7×7 内一敌 1 点 + 冻结 1 回合 | 极寒领域：自身 7×7 内敌人各 2 点 |
| 剑圣 | 剑刃风暴：自身 3×3 内敌人各 2 点 | 治疗守卫：自身 5×5 内友军 +2 血 | 无敌斩：闪到 7×7 内一敌身边，连斩 3 次各 1 点物理 |
| 混沌骑士 | 混沌飞弹：7×7 内一敌 1~3 点 + 眩晕 1~2 回合 | 实相裂隙：传送到 9×9 内一敌身边，2 点物理 | 混沌幻象：召唤 2 个幻象（1 血，攻击 1） |
| 斧王 | 狂战士之吼：眩晕 3×3 内敌人 1 回合，自身防御 +1 | 反击螺旋：3×3 内敌人各 1 点物理 | 淘汰之刃：3×3 内一敌，血 ≤3 斩杀，否则 1 点 |
| 屠夫 | 肉钩：直线 5 格内第一个敌人拉到身边，2 点物理 | 腐烂：3×3 内敌人各 1 点，自己也 1 点 | 肢解：3×3 内一敌 3 点，自己回 1 |

| 装备 | 效果 |
|---|---|
| 锁子甲 | 防御 +1 |
| 阔剑 | 基础攻击伤害 +1 |
| 速度之靴 | 移动 +2（还没移动的话本回合就生效） |
| 活力宝珠 | 血量上限 +2，并回复 2 |
| 治疗药膏 | 消耗品：回复 3 |

## 图标与头像

- `assets/icons/`：原创矢量图标（宙斯=闪电，混沌骑士=马首，天辉小兵=绿盾，夜魇小兵=红盾，卡面=剑）
- `assets/portraits/`：头像替换目录，放入同名 PNG 即可覆盖默认图标，说明见该目录的 README

## 操作

| 操作 | 按键 |
|---|---|
| 选棋子 / 移动 / 选目标 | 左键 |
| 出牌 | 点左侧攻击卡或底部手牌，再点红色高亮的敌人（无目标的牌直接生效） |
| 取消选目标 | 再点一次卡牌 / Esc |
| 缩放 | 滚轮 / 触控板双指捏合 |
| 平移 | 右键或中键拖动 / WASD / 方向键 / 触控板双指滑动 |
| 重新适配棋盘 | F |

## 目录

```
project.godot                 项目配置（GL Compatibility 渲染，兼容网页）
scenes/main.tscn              主场景
scripts/game.gd               规则：回合、移动、卡牌结算、泉水、胜负
scripts/piece_defs.gd         棋子与卡牌数据表
scripts/piece.gd              棋子（状态 + 绘制）
scripts/board.gd              棋盘（坐标 API、绘制、点击）
scripts/hud.gd                界面（回合信息、棋子信息、卡牌栏、日志、胜利面板）
scripts/card_view.gd          卡牌（炉石风格的卡面绘制）
scripts/camera_controller.gd  摄像机
scripts/float_text.gd         伤害/治疗飘字
scripts/background.gd         战场背景（天辉 / 夜魇两套，回合切换时淡入淡出）
tests/test_rules.gd           规则自动测试
assets/fonts/                 思源黑体（Noto Sans SC）常用字子集，SIL OFL 1.1 授权
export_presets.cfg            网页导出配置（单线程，无需特殊响应头）
.github/workflows/deploy-web.yml  推送后自动导出并发布到 GitHub Pages
```
