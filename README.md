# godot-dota2-chess

用 Godot 4.7 制作的回合制卡牌棋子游戏（MOBA 风格）。目前是本地双人（同一台设备轮流操作）的测试版。

## 规则（当前版本）

- 21×21 棋盘，蓝方泉水在左下 (0,20)，红方泉水在右上 (20,0)
- 一个棋子 = 一个角色；每个棋子有自己的基础攻击卡和技能卡
- 双方轮流行动，**每回合只能操作一个棋子**：移动一次（可选）+ 使用该棋子的一张卡牌（可选），顺序不限
- 一旦移动或出牌，本回合就锁定为这个棋子；移动和出牌都用完后自动结束回合，也可以随时点「结束回合」
- 移动：上下左右走，不能穿过棋子和泉水；射程按曼哈顿距离计算
- 冷却：技能使用后要再过 N 个己方回合才能再用
- 眩晕：被眩晕的棋子在接下来 N 个己方回合不能行动
- 泉水：每方回合开始时，己方泉水周围 2 格内的己方棋子 +10 生命，敌方棋子受到 20 伤害
- 胜利：消灭对方全部英雄

## 测试棋子

| 棋子 | 生命 | 移动 | 卡牌 |
|---|---|---|---|
| 宙斯（英雄，远程） | 60 | 2 | 普通攻击（射程3，6）· 连锁闪电（射程4，10 + 弹射2次各6，冷却2）· 雷击（射程7，16，冷却3）· 天罚（全场敌方英雄各12，冷却6） |
| 混沌骑士（英雄，近战） | 90 | 3 | 普通攻击（近战10，25%暴击双倍）· 混沌飞弹（射程4，6~16 + 眩晕1~2回合，冷却3）· 裂隙突袭（射程5，传送到目标身边 + 8，冷却3） |
| 士兵 | 25 | 2 | 普通攻击（近战5） |

数值全部在 `scripts/piece_defs.gd`，改这一个文件即可调整平衡或新增棋子/卡牌。

## 操作

| 操作 | 按键 |
|---|---|
| 选棋子 / 移动 / 选目标 | 左键 |
| 出牌 | 点底部卡牌，再点红色高亮的敌人 |
| 取消选目标 | 再点一次卡牌 / Esc |
| 缩放 | 滚轮 / 触控板双指捏合 |
| 平移 | 右键或中键拖动 / WASD / 方向键 / 触控板双指滑动 |
| 重新适配棋盘 | F |

## 目录

```
project.godot                 项目配置（GL Compatibility 渲染，兼容网页）
scenes/main.tscn              主场景
scripts/game.gd               规则：回合、移动、卡牌结算、泉水、胜负
scripts/piece_defs.gd         棋子与卡牌数据表
scripts/piece.gd              棋子（状态 + 绘制）
scripts/board.gd              棋盘（坐标 API、绘制、点击）
scripts/hud.gd                界面（回合信息、卡牌栏、日志、胜利面板）
scripts/camera_controller.gd  摄像机
scripts/float_text.gd         伤害/治疗飘字
tests/test_rules.gd           规则自动测试
assets/fonts/                 思源黑体（Noto Sans SC）常用字子集，SIL OFL 1.1 授权
export_presets.cfg            网页导出配置（单线程，无需特殊响应头）
.github/workflows/deploy-web.yml  推送后自动导出并发布到 GitHub Pages
```

## 测试

```bash
godot --headless --import
godot --headless -s res://tests/test_rules.gd
```

## 网页试玩

推送到 `main` 后，GitHub Actions 会自动导出网页版并发布到 GitHub Pages。
首次需要在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。
